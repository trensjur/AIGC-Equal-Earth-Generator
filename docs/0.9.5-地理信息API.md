# 0.9.5 地理信息查询 API

本版本在原有"星球半径"查询之外，新增了一组只读的地理信息查询入口，方便地图、指南针、
传送、任务等模组直接读取当前世界的球形地理参数，而不必依赖本模组内部类。

## 坐标与几何约定

| 项目 | 约定 |
| --- | --- |
| x 轴 | 经度方向；本初子午线位于 `x = 0` |
| z 轴 | 纬度方向；向北为负，赤道位于 `equatorZ` |
| 纬度 | 北纬为正，范围 `[-90, 90]` |
| 经度 | 东经为正；地图内为 `[-180, 180]`，跨越接缝时按 360° 周期理解 |
| 本初子午线 | 经度 0°，恒为 `x = 0` |
| 反子午线 / 接缝 | 经度 ±180°，`|x| = seamX(z)`；`OUTLINE` 模式下随纬度收缩 |
| 接缝环绕 | 跨过反子午线后回到本初子午线一侧，因此经度是周期性的 |

> **注意**：Equal Earth 是等面积投影，地图上的长度不等于星球上的真实长度。
> 地图上的子午线长度为 `2H`，而星球上的真实子午线弧长为 `πR`。
> 两者都通过 API 提供，命名上分别带有 `OnMap` / `Arc` 或 `Length` / `Width` 后缀。

## 公开类型

| 类型 | 说明 |
| --- | --- |
| `PlanetGeography` | 完整快照：半径、赤道周长、半子午线、赤道/极线、地图范围、面积、经纬度换算、大圆距离 |
| `MapBounds` | 地图包围盒：`minX` / `maxX` / `minZ` / `maxZ`，另有 `width()` / `height()` / `centerX()` / `centerZ()` / `contains(x, z)` |
| `GeographicPosition` | 某个方块坐标的纬度、经度、是否在地图轮廓内、陆地掩码，含 `format(decimals)` 格式化 |

`PlanetGeography` 是不可变记录，可以缓存；`SphericalWorldApi.getPlanetGeography(level)`
每次调用都会重新构建快照，热路径建议缓存。

## 查询入口

全部位于 `com.aigcs.e2generator.api.SphericalWorldApi`：

| 方法 | 含义 |
| --- | --- |
| `getPlanetGeography(level)` | 完整快照 `PlanetGeography` |
| `getPrimeMeridianX(level)` | 本初子午线 x（恒为 0） |
| `getAntimeridianX(level)` | 赤道处的反子午线 x |
| `getAntimeridianXAt(level, z)` | 指定 z 处的反子午线 x |
| `getMeridianLengthOnMap(level)` | 地图子午线长度 `2H` |
| `getMeridianArcLength(level)` | 星球真实子午线弧长 `πR` |
| `getEquatorZ(level)` | 赤道 z |
| `getEquatorWidth(level)` | 赤道处的地图宽度 `2Hr` |
| `getEquatorLength(level)` | 赤道真实周长 `2πR` |
| `getNorthPoleZ(level)` / `getSouthPoleZ(level)` | 北极线 / 南极线 z |
| `getMapBounds(level)` | 地图包围盒 `MapBounds` |
| `getPlanetSurfaceArea(level)` | 球面面积 `4πR²` |
| `getMapArea(level)` | 投影后地图面积（等面积投影下与球面面积一致） |
| `getLatitude(level, z)` | z → 纬度 |
| `getLongitude(level, x, z)` | (x, z) → 经度 |
| `getZForLatitude(level, latitude)` | 纬度 → z（纬度夹取到 ±90°） |
| `getXForLongitude(level, longitude, z)` | 经度 → x |
| `getGeographicPosition(level, x, z)` | 方块坐标 → `GeographicPosition` |
| `isInsideMap(level, x, z)` | 是否在地图轮廓内（不判断缓冲带与陆地） |
| `getLandMask(level, x, z)` | 陆地掩码：0 = 海洋/地图外，1 = 陆地 |
| `getSurfaceDistance(level, lat1, lon1, lat2, lon2)` | 两点间球面大圆距离（方块） |

已有方法保持不变：`getWorldShape`、`isSphericalWorld`、`getPlanetRadiusChunks`、
`getPlanetRadiusBlocks`、`getPlanetCircumference`、`getRecommendedDistantHorizonsCurveRatio`、
`radiusChunksOf`、`radiusBlocksOf`。

生成器侧接口 `PlanetRadiusProvider` 新增默认方法 `planetGeography()`，
内置 `NoiseBasedChunkGenerator` Mixin 已实现；旧实现不覆盖时返回 `Optional.empty()`。

## 示例

```java
LevelAccessor level = ...;

// 本初子午线与反子午线
OptionalDouble prime = SphericalWorldApi.getPrimeMeridianX(level);
OptionalDouble anti = SphericalWorldApi.getAntimeridianXAt(level, player.getZ());

// 当前位置的地理信息
Optional<GeographicPosition> here =
        SphericalWorldApi.getGeographicPosition(level, player.getX(), player.getZ());
here.ifPresent(pos -> player.displayClientMessage(
        Component.literal("位置：" + pos.format(3)), true));

// 经纬度 → 坐标（例如任务点）
SphericalWorldApi.getPlanetGeography(level).ifPresent(geo -> {
    double x = geo.xAt(39.9, 116.4);   // 纬度、经度
    double z = geo.zAt(39.9);
    double distance = geo.surfaceDistance(39.9, 116.4, 31.2, 121.5);
});
```

## 空值与端侧行为

- 所有静态入口允许传入 `null`：返回 `Optional.empty()` / `OptionalDouble.empty()` /
  `false` / `null`，不会抛异常。
- 非球形世界（或客户端尚未收到同步）统一返回空值。
- 服务端结果来自生成器上挂载的 `WorldShape`，权威可信；
  客户端使用登录/换维度时服务端同步过来的形状。
- `PlanetGeography` 中的 `radiusChunks` / `radiusBlocks` 与创建世界时选择的半径一致，
  不再做 64 ~ 64000 区块的夹取，以如实反映配置文件直接指定 `halfMeridian` 的世界。

## 命令

`/sphere geography`（别名 `/sphere geo`）会输出：

1. 星球半径（区块 / 方块）与赤道周长；
2. 本初子午线 x 与赤道处反子午线 x；
3. 赤道 z、北极线 z、南极线 z；
4. 地图包围盒；
5. 地图子午线长度、真实弧长、赤道地图宽度、地图面积。

## 验证建议

1. 新建默认世界（R = 500 区块），执行 `/sphere geo`，检查半径、赤道、极线、范围。
2. 在出生点执行 `/sphere coords`，再用 `getGeographicPosition` 对比经纬度是否一致。
3. 传送到经度 ±179° 附近，确认跨接缝后经度回到 ±180° 一侧且 `x` 被包裹。
4. 用 `/sphere locate 0 0` 与 `getXForLongitude/getZForLatitude` 对比，应落在本初子午线与赤道交点。
5. 用 `getSurfaceDistance` 计算赤道上经度相差 180° 的两点，结果应约为 `πR`（半周长）。
