# 0.9.6 天空与环境配置

本版本新增客户端天空 / 环境视觉效果、8 槽位本地预设库，以及内置的 `gameassets`
资源包。所有功能都只影响客户端渲染，不改变服务端世界生成或存档数据。

## 1. 配置项

配置位于 `config/e2generator-client.toml`（客户端配置），同时可在 NeoForge 的
“模组配置”界面中调整。

| 键 | 默认值 | 范围 | 说明 |
| --- | --- | --- | --- |
| `skyTiltEnabled` | `true` | — | 是否启用额外的日月轨道倾斜 |
| `skyTiltAuto` | `true` | — | 按玩家位置自动计算；否则使用固定角度 |
| `skyTiltStrength` | `1.0` | `-2.0 ~ 2.0` | 自动倾斜强度（纬度 × 强度） |
| `skyManualTilt` | `0.0` | `-90 ~ 90` | 固定倾斜角（度） |
| `sunTextureScale` | `1.0` | `0.25 ~ 4.0` | 太阳贴图渲染缩放 |
| `moonTextureScale` | `1.0` | `0.25 ~ 4.0` | 月亮贴图渲染缩放 |
| `celestialTextureScale` | `1.0` | `0.1 ~ 4.0` | 其它天体缩放（例如 Ad Astra 行星） |
| `adAstraCompatibility` | `true` | — | 是否对 Ad Astra 自定义天空应用倾斜与缩放 |

## 2. 自动日月倾斜

### 2.1 球形世界

优先使用本模组同步到客户端的 `WorldShape`：

```text
latitude = shape.latitudeAt(player.z)          // -90 ~ 90
tilt     = clamp(latitude * skyTiltStrength, -89, 89)
```

玩家向南 / 向北移动时，日月轨道会随之倾斜；在赤道为 0°，越靠近极线越明显。

### 2.2 非球形维度

没有赤道信息时（例如 Ad Astra 的行星维度），退化为按 z 坐标估算：

```text
latitude ≈ clamp(player.z / 30000 * 90, -90, 90)
```

如果 `skyTiltAuto = false`，则直接使用 `skyManualTilt`。

### 2.3 原版渲染注入点

`LevelRendererMixin` 注入 `LevelRenderer#renderSky`：

- 用 `@ModifyConstant` 修改太阳 / 月亮的四边形半边长（30 与 20）；
- 在原版 `Axis.XP.rotationDegrees(timeOfDay * 360)` 之后追加
  `Axis.ZP.rotationDegrees(tilt)`，只影响日月轨道，不影响天空盒与日出光晕。

因此该功能只在**原版天空**（`DimensionSpecialEffects.SkyType.NORMAL` 且没有自定义
天空渲染器）时生效；Sodium / Iris 等替换了天空渲染的模组可能使其不可见，但不会崩溃。

## 3. Ad Astra 兼容

Ad Astra 使用自己的 `ModSkyRenderer` 渲染太阳、月亮、行星与背光。本模组提供独立的
可选 Mixin 配置 `e2generator.adastra.mixins.json`：

- `AdAstraMixinPlugin` 在未安装 `ad_astra` 时跳过整个配置；
- `AdAstraSkyRendererMixin` 定位
  `earth.terrarium.adastra.client.dimension.ModSkyRenderer#renderSkyRenderable`；
- 根据贴图路径区分缩放：
  - 路径包含 `moon` → `moonTextureScale`；
  - 路径包含 `sun` → `sunTextureScale`；
  - 其它（行星、背光等）→ `celestialTextureScale`；
- 把当前倾斜角叠加到 `globalRotation.z`，与 Ad Astra 自己的旋转逻辑兼容。

Ad Astra 本体不随本模组分发；`adAstraCompatibility = false` 可以完全关闭对本模组
Ad Astra Mixin 的数值影响（Mixin 仍然应用，但直接返回原值）。

## 4. 内置资源包 `gameassets`

### 4.1 注册与默认启用

- 资源包位于模组 jar 根目录的 `gameassets/`，通过 `AddPackFindersEvent` 注册为
  **独立、可开关** 的资源包（Pack id：`mod/e2generator:gameassets`）。
- `OptionsMixin` 在 `Options#loadSelectedResourcePacks` 执行前，首次启动时把该 Pack
  加入默认选中列表；随后写入标记文件
  `config/e2generator-resourcepack-default.json`。
- 标记文件存在时不再自动启用，因此玩家在“资源包”界面关闭后，下次启动不会反弹。

### 4.2 目录结构

```text
gameassets/
├── pack.mcmeta                 # pack_format 34（1.21.1），supported_formats 15~999
├── pack.png
├── LICENSE.txt                 # Ad Astra 3D 素材的 MIT 许可证与署名
└── assets/
    ├── minecraft/textures/environment/sun.png      # 原版太阳
    ├── minecraft/textures/environment/moon_phases.png  # 原版月亮相位（由 moon.png 生成）
    ├── ad_astra/textures/environment/*.png         # Ad Astra 太阳/月亮/行星/背光
    ├── adastraextra/textures/sky/*.png             # Ad Astra Extra 行星
    ├── stellarview/textures/environment/...        # Stellar View 太阳/月亮/主要行星（附加）
    ├── environment/*.png                           # 通用环境贴图（兼容/预览）
    └── sky/                                        # 通用天空贴图与 GUI 预览
        ├── *.png
        └── gui/*.png
```

`environment` 与 `sky` 通用目录会保留在包内，方便其它读取这些命名空间的模组或后续
功能使用；实际生效的是 `minecraft`、`ad_astra`、`adastraextra` 的标准路径。

## 5. 本地预设库（8 槽位）

- 文件：`config/e2generator-sky-presets.json`
- 容量：固定 8 个槽位，空槽位为 `null`
- 内容：倾斜开关 / 自动模式 / 强度 / 固定角度 / 三种缩放 / Ad Astra 兼容开关
- 入口：NeoForge 配置页底部的“打开本地预设库”；每行提供加载、保存、删除
- “重置天空设置”按钮会把上述 8 个配置恢复默认值，并立即写回客户端配置

示例：

```json
{
  "version": 1,
  "presets": [
    {
      "name": "Preset 1",
      "tiltEnabled": true,
      "tiltAuto": true,
      "tiltStrength": 1.0,
      "manualTilt": 0.0,
      "sunScale": 1.0,
      "moonScale": 1.0,
      "celestialScale": 1.0,
      "adAstraCompat": true
    },
    null,
    null,
    null,
    null,
    null,
    null,
    null
  ]
}
```

损坏或超出范围的数值会在加载 / 应用时夹取；读取失败只会记录日志，不会影响游戏启动。

## 6. 验证清单

1. 启动客户端，确认“资源包”界面出现“AIGC 的 Equal Earth 天空与环境材质包”，且默认在左侧选中。
2. 关闭该资源包 → 重启游戏，确认不会被自动重新启用。
3. 调整 `sunTextureScale` / `moonTextureScale`，确认日月大小立即变化。
4. 在球形世界南北移动，确认日月轨道倾斜角随纬度变化；关闭 `skyTiltAuto` 后使用固定角。
5. 安装 Ad Astra 后进入行星维度，确认行星/太阳材质来自 `gameassets`，且缩放与倾斜生效。
6. 保存 8 个预设、逐个加载、删除槽位，重启后确认 `config/e2generator-sky-presets.json` 保留。
7. 点击“重置天空设置”，确认 8 个配置恢复默认值。
